## Git 约定

**commit message 格式**

```
feat:  新功能 / 新练习
notes: 纯笔记更新
fix:   修 bug
docs:  文档调整
```

例：`feat: 第一周基础语法练习`、`notes: Day2 基本数据类型表`

**提交节奏**：不用每天提交。每周六的 Git 时段统一提交一次即可（第 1 周任务清单已排进周六 16:30–17:00）。

**⚠️ 首次提交用的是临时占位身份**，推送到 GitHub 之前先改掉：

```bash
cd /d D:\java-learning
git config user.name "你的GitHub用户名"
git config user.email "你的GitHub邮箱"
git commit --amend --reset-author --no-edit
```
