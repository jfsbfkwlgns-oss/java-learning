# 03-项目

代码产出地。第 1 周从这里起步。

## 目录约定

```
03-项目/
  第01周-简易计算器/
    src/
    README.md      ← 这个项目解决了什么、怎么跑、踩了什么坑
  第02周-计算器重构/
  ...
  capstone/        ← 阶段 1 主项目：Java SE + JDBC 分层工程
```

## 第 1 周要做的

**控制台「简易计算器」**（周六 14:00–15:30，1.5h）

必须包含：
- [ ] 输入两个数 + 一个运算符，输出结果
- [ ] 除零判断
- [ ] 非法运算符提示
- [ ] **用循环让用户可以连续计算多次**

它的价值不在难度，在于它是**你自己写的**，不是跟着教程敲的。

## 每个项目的 README 写什么

```markdown
# 第__周 · 项目名

## 做什么
## 怎么运行（贴命令）
## 我踩的坑（从台账第九节「卡点记录本」挑）
## 下次可以改进的点
```

**"我踩的坑"这一节别省。** 阶段 2 写主项目 README「核心难点」时直接从这儿挑，面试被问"遇到过什么困难"也靠它。
