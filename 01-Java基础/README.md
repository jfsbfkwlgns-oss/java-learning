## 笔记模板（照抄，别自由发挥）

```markdown
# Day__ · 主题（日期）

## 1. 今天学了什么（3 行以内）
- 

## 2. 自己写出来的东西
（贴代码，或指向同目录的 .java 文件）

## 3. 踩到的坑 / 还没搞懂的
- 

## 4. 能不能脱稿讲给别人听？
□ 能  □ 看得懂但讲不清  □ 不会
```

第 4 项是判据：**只有"能脱稿讲"才算学会。** 打不上勾的，周末补漏时段优先处理它。
