# 04-周复盘

每周日写一份，文件名 `第01周复盘.md`。

**注意**：先填《学习进度台账》第二节的完成率，再来这里写 5 行；两块内容都要**原样贴到对话里**给陪练看。

## 模板（照抄）

```
【第 __ 周复盘】____年__月__日

1. 本周实际完成：________（对照上周计划，完成率 __%）
2. 没完成的是：________
3. 原因分类：□ 时间不够  □ 难度超出预期  □ 计划本身不合理  □ 状态问题
4. 本周最有价值的收获（一个知识点或一个坑）：________
5. 下周调整：________
```

## 三条规则

| 规则 | 说明 |
| --- | --- |
| 完成率 ≥ 70% 即达标 | 不满 100% 不自责 |
| 连续 2 周 < 50% | 计划定太大了，周目标砍 1/3，别硬撑 |
| 第 3 项必须选原因分类 | 不写流水账，要归因 |

**不用汇报得漂亮。** 完成率 40% 就直接写 40%，虚报最后亏的是自己。
**断更了不用道歉、不用补写。** 直接从本周继续。
